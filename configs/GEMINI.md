# Instructions for Long-Context AI Workflows & Gemini CLI

## Context Optimization
- Take full advantage of large context windows (1M+ tokens) by reading the entire repository structure before proposing changes.
- Cross-correlate tests, documentation, and implementation files to prevent regression.

## Output Standards
- Deliver full, unified search/replace blocks or self-contained patches.
- Highlight breaking changes, environment variables, or schema migrations at the top of the response.
- Adhere strictly to the existing codebase formatting (Prettier, Black, rustfmt).
