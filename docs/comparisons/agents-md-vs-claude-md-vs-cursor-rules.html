2. The 2026 Token-Saving Rule

⚠️ Empirical Finding: Pasting full directory trees into root instruction files increases token spend by 20%+ and degrades agent reasoning by 18%.

Modern coding agents already construct Tree-sitter AST maps automatically. Your context files should strictly contain non-inferable build commands, negative constraints (what NOT to do), and commit standards.

3. Production-Ready AGENTS.md Template (Under 50 Lines)

# AGENTS.md — Universal Agent Context Specification

## 1. Project Overview & Architecture
- Stack: TypeScript / Node.js (or Python 3.12 / FastAPI)
- Structure: Modular services under `src/`, test suites under `tests/`.

## 2. Essential Commands (Non-Inferable)
- Build: `npm run build`
- Fast Test Loop: `npm test -- --bail`
- Lint & Format: `npm run lint`

## 3. Negative Constraints (What NOT to Do)
- NEVER commit secrets, API keys, or `.env` files.
- NEVER delete or overwrite existing docstrings or test suites without explicit instructions.
- DO NOT use wildcard imports (`from module import *`).
- DO NOT add external dependencies for tasks solvable with standard libraries.

## 4. Code Style & Typing Standards
- All code must pass strict type checking without warnings (`strict: true`).
- Keep functions modular and under 50 lines. Keep files under 300 lines.
- Commits must adhere to Conventional Commits: `feat:`, `fix:`, `refactor:`, `test:`, `docs:`.
